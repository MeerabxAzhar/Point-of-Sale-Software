# Point of Sale (POS) System in Java (NetBeans + Database)

This project is a Point of Sale (POS) application developed in Java using NetBeans with a fully integrated database backend for efficient data management. The software provides a user-friendly interface and supports all essential POS operations to streamline sales and inventory management.

# Key Features:

- CRUD Operations: Create, Read, Update, and Delete records for products, customers, and transactions.
- Product Management: Add new products, update existing details, search items, and delete products from the system.
- Customer Management: Maintain customer records including personal details and purchase history.
- Billing System: Generate real-time bills for purchases, calculate totals, and maintain transaction logs.
- Search Functionality: Quickly search products or customers using various filters.
- Database Integration: All records (customers, products, and sales) are securely stored in the database for consistency and reliability.
- Inventory Tracking: Keep track of product listings and updates in stock levels.
- Warning on low stock: generates a warning pdf when the stock is low listing all the products that are low in stock.

This POS system provides a complete solution for small to medium businesses by combining sales, customer data, and product inventory into one efficient platform. It ensures data accuracy, easy retrieval, and smooth billing, making daily operations faster and more reliable.

# Pre-requirements:

- NetBeans IDE (version 8.2 or later recommended)
- Java Development Kit (JDK 8 or higher)
- Database Management System (e.g., MySQL, SQLite, or PostgreSQL)
- JDBC Driver for database connectivity
